<h2><img src="assets/icons/principles.svg" width="26" height="26" align="absmiddle" alt="" /> Core Principles</h2>

- **Local-First** — Software works offline by default; data lives on your device, not on a central server.
- **Privacy by Design** — Zero trackers, zero ads, zero telemetry. Cryptography protects users instead of profiling them.
- **Open Source** — Public, auditable code where trust comes from transparency rather than promises.

<h2><img src="assets/icons/background.svg" width="26" height="26" align="absmiddle" alt="" /> Background</h2>

<details>
<summary><b>Why local-first?</b></summary>

For the past few years, I've built software on constrained hardware, switching between a PC with motherboard issues and my phone.

During a hardware repair attempt, I lost nearly all of my childhood photos. That experience made the case for local-first software deeply personal: people should truly own their data without relying on fragile setups or cloud platforms that can lock or disappear.

I'm currently saving up for a reliable development workstation so I can continue building and maintaining open-source tools without interruption.

</details>
